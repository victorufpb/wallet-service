# Getting Started

### Reference Documentation
This project was made to simulate a wallet service, to have operations as transfer, withdraw and deposit.
The service is responsible for managing user's money.

### Requirements

* Java 17+
* Gradle
* Docker

### How to run
It is necessary to execute gradle to build and run the project, and run docker compose to initiate project's requirement
* navigate until docker folder, and execute "docker-compose up"
* gradlew clean build
* gradlew bootRun
